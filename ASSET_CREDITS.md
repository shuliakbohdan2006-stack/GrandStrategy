# Asset Credits

## Map Data

- Natural Earth Admin 0 Countries, 1:110m scale
- Local file: `data/ne_110m_admin_0_countries.geojson`
- Source: https://www.naturalearthdata.com/
- License: public domain
- Retrieved for this prototype: 2026-07-01

## Flags

- Flag PNGs are stored in `assets/flags/` and keyed by ISO alpha-2 code.
- Source used by the prototype: FlagCDN, https://flagcdn.com/
- Flag images are based on public-domain country flag designs where available; check FlagCDN's current attribution and usage notes before redistribution.
- Retrieved for this prototype: 2026-07-02

## Generated Prototype Assets

- UI icons in `assets/icons/`, sounds in `assets/sounds/`, and `assets/images/menu_background.png` were generated locally for this prototype.
- These generated assets are intended as placeholder production art for the prototype and can be replaced by authored assets later.

## Fonts

- `assets/fonts/` is optional. The game falls back to Segoe UI when no bundled font files are present.
